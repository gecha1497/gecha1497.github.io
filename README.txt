GETANEH TILAHUN — INTERACTIVE ACADEMIC & PROFESSIONAL PORTFOLIO

FILES
- index.html: complete self-contained website. CSS and JavaScript are embedded.

OPEN LOCALLY
1. Extract the ZIP archive.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No server, framework, build step, or internet connection is required for the website interactions.

INTERACTIONS TO TEST
- Use the moon/sun button in the header to change between light and dark themes.
- On a narrow screen, use the menu button to open/close navigation.
- Use the tabs in Teaching & Mentoring to change the displayed topic.
- Use the project category filters and search box together.
- Select “View project details” to open the project information dialog; close it with the buttons, outside click, or Escape.
- Copy the email address from the Contact section.
- Select “Print / Save PDF” to use the browser's print dialog.
- Scroll to see the reading progress line, active navigation item, reveal animations, and back-to-top button.
